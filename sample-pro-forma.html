How to Read This Pro Forma

PropertyThesis carries the same operating assumptions into valuation, financing, return analysis and sensitivity testing. The pro forma is not an isolated spreadsheet: it is the operating backbone for the investment recommendation and final report. In a live analysis, changing rent, vacancy, expenses, financing or exit assumptions updates the connected results.
