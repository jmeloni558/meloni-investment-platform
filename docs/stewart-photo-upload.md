# Upload a Stewart property's photos

Load the unpacked PropertyThesis Importers 1.4.1 extension in Edge (download the ZIP from the Stewart BPO). This version needs access to www.protk.com for the photo gallery.

1. Open the HomeSteps order in the same Edge profile. In PropertyThesis, choose **Comparable Sales → Stewart Valuation Intelligence — HomeSteps BPO**. Click **Upload photos to Stewart** on the saved property or next to **Export for Stewart** in the editor.
2. PropertyThesis looks for a completed PT Photos set. A missing or ambiguous match offers a local PT Photos folder picker. The browser cannot search OneDrive folders without you selecting one. The selected set's full address must match exactly one open Stewart case, including its unit.
3. Review the upright previews. Use **Rotate 90°** for any exception and choose categories where a photo description doesn't identify the view. **Mark No for repair items** starts checked when launched from the BPO. Clear it to leave the answers alone.
4. Click **Upload to Stewart** and keep both tabs open. The extension sends one photo at a time, preserves existing matching filenames and labels, then saves and reopens Photos/Files to check the results. Use the same source and capture order when retrying. If a label is already used, select an additional interior or exterior category for the other view. If an existing photo needs rotation, use Stewart’s photo editor.

This action never submits the BPO. If the browser cannot decode a photo, convert a copy to JPEG and retry from a folder. The optional Codex workflow remains available for assisted visual labeling.
